一、QARPilot

1. QARPilot 是什么？

面向飞行员与航空从业者的 QAR 事件复盘工具：导入飞行数据文件 → 查看事件结论、证据链、数据质量 → 用轨迹回放与航向/风向盘复看关键阶段，并可生成结构化的辅助讲评。

2. 支持哪些文件格式？

CSV、XLS、XLSX，以及已导出的 SampleCard JSON。选择文件后由解析服务返回结构化结果，App 只负责呈现，不在界面层重新计算规则或评分。

3. 导入后一直解析不出来 / 解析失败怎么办？

解析由解析服务完成，因此需要该服务可达（本机或同一局域网内）。请按序排查：① 确认解析服务已启动；② 确认手机与运行服务的电脑在同一网络；③ 确认所选文件属于支持格式且未损坏；④ 在应用设置的解析服务地址里核对地址是否正确。若仍失败，请把文件名类型与错误提示截图发给我们。

4. AI 辅助讲评需要联网吗？数据会发到哪里？

该功能为可选项：需要你在设置中自行填写第三方 API 地址与密钥后才会向你指定的接口发送当前样本数据。我们不经手、不保存相关请求与密钥；不启用该功能时，离线查看结论、证据与轨迹回放均不受影响。详见隐私政策。

5. 我的数据存在哪里？怎么删除？

样本索引与设置保存在设备本地。你可以在样本库中删除已保存的样本；卸载应用会一并清除应用沙盒内的数据。

6. 是否收费、是否有内购？

是否收费及是否包含内购，以 App Store 应用页面显示的信息为准；如后续调整，我们会在应用内与 App Store 页面同步说明。

二、AeroLingo

1. AeroLingo 是什么？

面向民航飞行员英语（ICAO 4/5 等级与 PEPEC 备考方向）的学习工具：按天的学习任务、句子跟读练习（录音与回听）、间隔重复复习与学习进度看板。

2. 需要联网吗？离线能用吗？

离线优先：已下载的内容、跟读录音与播放、复习计划与进度记录都可以在无网络环境下正常使用，网络不可用不会阻塞学习流程。

3. 为什么要麦克风权限？会不会被偷偷录音？

麦克风仅用于录制你主动发起的跟读练习，用于回听与自评；只有在你点击"开始录音"后才会录音，不会在后台自动录音。你可以在系统设置中关闭麦克风权限，关闭后其余功能仍可使用。

4. 我的录音保存在哪里？怎么删除？

录音保存在应用自身的沙盒目录中，只有本应用可访问，不会自动上传。你可以在「设置 → 录音与隐私」查看本地录音记录并删除；卸载应用会一并清除。

5. 在线评测是什么？会上传我的录音吗？

在线评测是可选的语音评测通道：如启用，App 会在上传前单独请求你的授权并说明用途与删除规则，音频仅用于本次训练分析，云端最多保留 24 小时；你可以拒绝或随时撤销授权。当前版本默认以离线方式运行，不使用在线评测。

6. AeroLingo 是官方考试软件吗？

不是。AeroLingo 是独立的备考学习工具，非官方应用，与民航局、ICAO、PEPEC 主办或承办机构均无隶属或合作关系；应用内的评测结果仅作为训练反馈，不代表也不预测任何官方考试结果。

7. 应用崩溃 / 打不开怎么办？

请先尝试：① 更新到最新版本；② 强制重启应用；③ 重启设备；④ 需要时卸载后重装（本地数据会一并清除，请先确认无需要保留的录音）。若仍无法解决，请把机型、系统版本与复现步骤发给我们。

8. 是否收费、是否有内购？

是否收费及是否包含内购，以 App Store 应用页面显示的信息为准。
